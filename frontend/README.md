# Om Muruga Sarees frontend

Standalone React + Vite demo using `src/data/products.json` and `src/mock-store.js`.

```sh
npm ci
npm start
```

No API, backend or environment variables are needed. Checkout and newsletter signup are simulated locally, with no payments or emails.

For Vercel: Root Directory `frontend`, Framework `Vite`, Install `npm ci`, Build `npm run build`, Output `dist`. `vercel.json` handles SPA deep links and refreshes. If deploying this folder alone, use the same settings with the project root set to this folder.

See the repository README for details. Run `npm test` and `npm run build` before deployment.
